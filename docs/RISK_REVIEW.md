# 风险说明

World-Cup-XLayer-Copilot 是黑客松 Demo 和开源项目。它展示真实 X Layer 合约和 USDT0 市场能力，但不构成投资建议。

## 用户需要知道

- 数字资产交易有风险。
- 交易需要用户自己在钱包里确认。
- 插件只做分析和入口，不替用户做投资判断。
- 体育数据、AI 分析和参考概率都可能出错。
- 正式比赛结果应以官方赛事结果为准。

## 产品边界

- 插件不保存钱包私钥。
- 插件不发起链上写交易。
- 用户模型 Key、ASR Key、体育 API Key 保存在本地浏览器设置。
- Dapp 只在用户确认后发起钱包交易。
- Polymarket 等外部市场只能作为参考信号，不是本项目合约结算依据。

## 合约风险控制

- 每个市场有总池上限。
- 每个用户有 stake 上限。
- 合约支持 void refund。
- 非 void 结算不能落到空 winning pool。
- 当前版本适合 Demo 和小额试验，扩大使用前应补充更成熟的治理、审计和结算流程。
