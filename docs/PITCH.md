# 产品卖点

World-Cup-XLayer-Copilot 是一个轻量级 Chrome 插件形态的“AI 陪你看球”世界杯助手：用户可以很轻松地安装在浏览器里，在看比赛、看集锦、看赛事页面时直接使用。它能帮用户看懂比赛、理解球员和局势、回看刚才发生了什么，并把比赛分析直接连接到 X Layer 上的预测市场入口。

## 一句话

**一个轻量 Chrome 插件，AI 陪你看世界杯：实时分析局面，识别刚才闪过的球员，听懂解说，补全球队和球员背景，并一键直达低成本、真实可用的 X Layer 预测市场。**

## 核心卖点

### 1. AI 陪你看比赛

用户不用自己查资料、翻阵容、看复杂盘口。插件在比赛旁边当一个懂球的 AI 副驾驶，随时回答：

- 现在局势怎么样？
- 哪支队更占优？
- 刚才发生了什么？
- 这个球员是谁？
- 这个球员以前表现怎么样？
- 解说刚才在说什么？
- 这场比赛的市场怎么看？

它不是一个普通聊天框，而是跟当前比赛页面、赛事数据、球员资料、临时回看和市场信息连在一起的观赛助手。

### 2. 轻量 Chrome 插件，安装简单，适用面广

它不是一个需要用户专门打开的新平台，而是一个可以直接装进 Chrome 的轻量插件。用户可以在看直播、看回放、看 YouTube 集锦、看 FIFA 页面、看新闻和数据页面时随时打开侧边栏。

这个形态的优势很直接：

- 安装门槛低，用户不用迁移到新 App。
- 使用场景广，只要在浏览器里看球或查比赛，就可以呼出 AI 助手。
- 不打断观赛流程，AI、数据和市场入口都贴在旁边。
- 插件先帮用户理解比赛，真正交易再跳到更安全的 Dapp。

### 3. 刚才没看清，AI 帮你回看

比赛里很多关键瞬间只有几秒：镜头切走、字幕闪过、解说太快、球员名字没看清。临时回看能力可以帮用户补上这一段。

用户可以直接问：

- “刚才那个球员是谁？”
- “刚才谁进了球？”
- “刚才画面里发生了什么？”
- “刚才解说在说什么？”

图片可以交给视觉模型判断，音频可以交给 ASR 转写，再由 AI 结合比赛上下文解释。这让插件不只是“赛后总结”，而是真正在观赛过程中帮用户理解现场。

### 4. 一键数据接入，历史和实时数据都准备好

产品本身已经把大量世界杯相关数据整理成可用的数据包，包括：

- 赛程和比赛信息
- 国家队和球队别名
- 球队历史战绩
- 球队近期状态
- 国家队交锋记录
- 球员和关键球员资料
- 历史射手数据
- 世界杯 roster 和模拟名单层
- 球场、城市和赛事上下文
- 数据来源和引用信息

用户进入一场比赛后，不需要手动下载一堆文件。核心数据会自动准备，当前比赛需要的球队、球员、历史上下文会按需加载。

同时，实时数据可以通过体育 API 接入，例如比赛状态、赛程快照、实时比分、赛事事件等。历史数据负责“理解背景”，实时数据负责“跟上现场”。

这套数据能力本身就是产品卖点：AI 不是凭空猜，它背后有结构化赛事数据库、历史上下文和实时 API。

### 5. 球员不只是名字，而是故事

用户问“这个人是谁”，AI 不只回答一个名字。它可以进一步解释：

- 他是哪支队的关键球员
- 他在国家队或历史数据里的位置
- 他以前有什么代表性表现
- 他和当前比赛有什么关系
- 他可能为什么被重点关注

这让普通观众也能快速理解球员背景，不需要自己跳到多个网站查资料。

### 6. 比赛分析和预测市场在同一个入口

用户刚看懂局面，就能看到与这场比赛相关的 Team A / Draw / Team B 市场入口。它把“看比赛”“问 AI”“看市场”放在同一个体验里。

这比普通预测市场更接近真实观赛场景：用户不是先去交易页面找比赛，而是在看球时自然看到这场比赛的市场。

### 7. 一线直达 X Layer，链上交易更轻

产品把预测市场交易放到 X Layer 上，适合世界杯这种高频、低金额、强互动的场景。

对用户来说，体验重点是：

- 入口轻
- 成本低
- 链上可查
- 钱包确认清楚
- 插件里先理解，Dapp 里再行动

插件负责把用户从观赛现场带到对应市场，Dapp 负责承接钱包连接和交易确认。

### 8. 用户自带模型和 Key，更开放

产品不强行绑定某一个 AI 供应商。用户可以配置自己的文本模型、视觉模型和音频转写服务。

这带来三个好处：

- 成本可控：用户按自己的 Key 和套餐使用。
- 模型可选：可以接 OpenAI-compatible、国内外大模型、视觉模型和 ASR 服务。
- 数据更清楚：Key 存在本地，用户知道自己的请求发给谁。

### 9. 适合边看边问、边懂边行动

这个产品最核心的体验不是“打开一个工具”，而是陪在用户观赛旁边。

它把几个原本分散的动作串起来：

```text
看比赛
-> AI 解释局势
-> 回看刚才画面和解说
-> 补全球队和球员背景
-> 查看当前比赛市场
-> 跳转到 X Layer Dapp 行动
```

对用户来说，这就是一个从“我没看懂”到“我知道发生了什么、我知道市场怎么看、我可以马上行动”的完整链路。
