# World-Cup-XLayer-Copilot 视频素材

World-Cup-XLayer-Copilot 是一个轻量 Chrome 插件形态的 AI 世界杯观赛助手。用户可以在看直播、回放、集锦、FIFA 页面、新闻和数据页面时打开插件，让 AI 帮忙理解当前比赛、球员、局势、解说和市场信号。

产品的第一层是 Chrome 插件。它不要求用户迁移到另一个平台，而是贴在浏览器里，随时可以呼出。用户可以问：现在是哪场比赛？局势怎么样？刚才那个球员是谁？刚才解说说了什么？

产品的第二层是临时回看。比赛里很多关键瞬间只有几秒，画面切走、字幕闪过、解说太快。用户开启后，最近画面可以交给视觉模型，最近音频可以交给 ASR，再由 AI 结合比赛上下文回答。

产品的第三层是数据。项目整理了世界杯赛程、球队别名、球队历史、近期状态、国家队交锋、球员资料、关键球员、球场、城市和来源信息。当前比赛上下文会按需加载，实时体育 API 可以补充比分、赛况和事件。

产品的第四层是 X Layer。插件负责理解比赛和展示 Team A / Draw / Team B 市场入口。真正的钱包连接、授权和交易动作在独立 X Layer Dapp 里完成。项目使用 X Layer mainnet、USDT0、verified contract 和公开 registry，让黑客松评委能看到真实链上部分。

X Cup Hackathon 关注世界杯、X Layer、AI Agent、预测市场、交易、潜在市场价值、创新性、完成度和 Demo 展示。World-Cup-XLayer-Copilot 的核心故事是：AI 陪你看比赛，帮你理解现场，再把观赛注意力自然接到 X Layer 市场。
